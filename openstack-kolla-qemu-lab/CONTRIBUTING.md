# 🤝 Learning and contributions

- Explain command location, purpose, impact and expected result.
- Separate observed evidence from expectations.
- Never attach live credentials or unsanitized client/provider data.
- Test in a dedicated lab, not a production controller.
- Keep planned features separate from completed capabilities.
- Reference release-specific upstream documentation.

Suggested commit prefixes: `docs:`, `fix:`, `feat:`, `chore:`.
